Tentang

Saya membangun sampai benar-benar terbukti

Ketertarikan saya pada keamanan sistem tumbuh saat menyusun tugas akhir: bagaimana satu QR code bisa menyimpan data rahasia, membuktikan keasliannya sendiri, sekaligus tetap terlihat seperti QR code biasa. Pertanyaan itu membawa saya membangun OurTicket dari nol di Universitas Indraprasta PGRI, merancang sendiri tiap lapisan keamanannya.

Di luar riset keamanan, saya senang mengerjakan sesuatu sampai tuntas, dari rancangan antarmuka sampai struktur basis data. Saya mencari tim tempat saya bisa terus belajar sambil membawa cara kerja yang saya bangun selama kuliah: memastikan sesuatu berfungsi bukan cuma sekali, tapi juga saat benar-benar diuji.

Empat lapisan keamanan yang saya kuasai

Enkripsi data

ECDSA · secp256r1

Tanda tangan digital

Menerapkan skema kurva eliptik NIST P-256 sehingga setiap tiket punya bukti keaslian yang tidak bisa disangkal penerbitnya.

LSB Steganografi

Penyembunyian data

Nonce + HMAC-SHA256

Anti-replay

Menambahkan nonce dan timestamp pada setiap payload untuk mencegah tiket yang sama dipindai atau dipakai ulang secara curang.

Proyek

Yang sudah saya bangun

E-ticketing security · Tugas akhir · PHP · 2025–2026

OurTicket

Masalah

Tiket digital berbasis QR mudah diduplikasi atau dipalsukan bila kodenya hanya menyimpan data polos tanpa lapisan verifikasi.

Solusi

Setiap QR code dibangun sendiri dan membawa data terenkripsi, bertanda tangan digital, serta disembunyikan lewat steganografi, sehingga satu kode sekaligus rahasia, terverifikasi, dan tahan replay.

PHPAES-256ECDSA P-256LSB SteganographyMidtrans QRIS
Tonton penjelasan proyek

Arsitektur teknis

  • QR code dibangun sendiri dari algoritma dasar, bukan pustaka generator.
  • QR Code versi 10, error correction level M.
  • Steganografi LSB 2-bit di kanal RGB.
  • Payload 120-byte: nonce, timestamp, HMAC-SHA256, tanda tangan ECDSA.
  • Integrasi pembayaran QRIS via Midtrans.
  • 5 halaman laporan admin dengan ekspor CSV/PDF dan pipeline e-tiket PDF otomatis.

Kualitas citra hasil penyisipan

~47,46 dB PSNR

Perubahan piksel tidak kasat mata, tetapi kode tetap bisa dipindai normal.
